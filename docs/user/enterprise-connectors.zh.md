# 在独立 DH 中连接飞书和企业微信

[English](enterprise-connectors.md) | 中文

本指南将增强版 DH 连接到飞书和企业微信。DH 管理执行、模型设置和对话历史，平台管理账号权限。连接器不依赖融合版 RAGFlow 后端；远程任务仍可使用单独配置的 [RAGFlow 连接器](ragflow-connector.zh.md)。

## 启动与配置

安装依赖并构建增强版后运行 `pnpm run start:enhanced`。接收远程任务期间需保持 DH 运行。打开「设置 → 插件 → 插件配置」，其中「飞书连接器」和「企业微信连接器」相互独立，默认关闭。修改后先保存，再点「连接 / 检查已保存账号」。密钥写入 DH 凭据服务，重新打开卡片只显示是否已配置。在派发任务前，请先在 DH 配好可用模型。

## 连接飞书

1. 在[飞书开发者后台](https://open.feishu.cn/app)创建企业自建应用，开启机器人能力，将「App ID」和「App Secret」填入飞书卡片。默认服务地址为国内飞书；Lark 可在高级设置中使用 `https://open.larksuite.com`。
2. 按需申请应用权限：列出群聊、读取聊天历史、读取 Docx/Wiki、发送消息。[聊天历史接口](https://open.feishu.cn/document/server-docs/im-v1/message/list)对群消息有额外权限要求。发布应用版本，按平台要求取得管理员审批。把机器人加入目标群，并将文档授权给应用。应用凭据不等于个人账号的访问权限。
3. 要从飞书派任务，在应用事件配置中选择长连接接收事件，订阅 `im.message.receive_v1`（[官方事件说明](https://open.feishu.cn/document/server-docs/im-v1/message/events/receive)）。在 DH 开启「接收来自该平台的远程任务」及连接开关，保存并检查「已连接」。此方式不需要公网回调地址或用户 OAuth 重定向。
4. 给机器人发一条无敏感内容的测试消息。在 DH 刷新连接状态，核对最近发送者和会话 ID，点击「添加最近发送者」「添加最近会话」后保存。发送者名单为空时不会执行任务。群聊中需 @ 当前机器人，私聊也可触发任务。
5. 试着发送「读取这份质量文档，总结检验要求」，附上已共享的 Docx/Wiki 链接。也可在 DH 中说「列出我可以访问的飞书群聊」「读取会话 ID … 的最近消息」。工具详情展示实际结果和错误。

要让 DH 主动发消息，开启「允许 DH 主动发送消息」，并明确添加目标会话 ID。然后说「把这份总结发送到飞书会话 …」，每次模型主动发送都需在 DH 单次确认。已授权远程任务的回复直接回到原会话，无需额外确认。发送失败时消息可能已到达平台，请先检查目标聊天再重试。

## 连接企业微信

1. 在企业微信创建「智能机器人」，选择「API 模式」及「长连接」，把「Bot ID」和「Secret」填入企微卡片。这里不能使用群 webhook key 或企业自建应用的 Corp Secret。[WorkBuddy 配置指南](https://www.workbuddy.cn/docs/workbuddy/Wecom-Guide)介绍了相同的平台侧创建步骤。
2. 开启连接及远程任务接收，保存并连接。默认服务地址为 `wss://openws.work.weixin.qq.com`。将机器人加入允许的群，或打开其私聊。
3. 发一条无敏感内容的测试消息。在 DH 刷新状态，核对并添加对应发送者、会话 ID，保存。再发新任务：「在已连接的 RAGFlow 知识库中查找检验要求，并给出来源」。这需要另行配置 RAGFlow 连接器。DH 会通过机器人回复原会话。
4. 要主动发送，开启发送开关并列出准确的目标会话 ID。在 DH 中要求发送明确文本到该会话，再确认原生发送请求。

企微读取工具只列出当前进程中此机器人连接收到的会话和消息，不能获取任意群的早期历史或企业会话存档。重新连接会清空这份有上限的消息缓存；已经执行的任务仍保留在 DH 原生对话历史中。

## 执行与排查

每个平台、账号、会话、发送者组合对应独立的持久化 DH 对话。同一组合的任务依次排队，使用配置的 Agent 预设及工作目录。在 DH 查看执行记录并审批工具。机器人先确认收到任务，待整个 Agent 空闲后返回从该任务入账以来最后一段助手文本；期间在 DH 发出的后续消息也可能影响回复。目前不支持媒体传输或在即时通讯内点按钮审批。

「已连接」确认的是账号和连接认证，不代表所有资源均有访问权限。没有执行任务时，刷新状态并检查发送者及会话名单、接收开关、机器人群成员身份、飞书 @ 和事件订阅。队列满会显示状态提示，请在已有任务结束后重试。执行失败时检查模型配置和 DH 对话，读取资源失败时检查应用权限与共享范围。飞书个人用户 OAuth、多维表格及日历操作、企业会话存档需要额外的提供方。

## 开源实现依据

实现使用 MIT 许可的官方[飞书 Node SDK](https://github.com/larksuite/node-sdk)和[企业微信智能机器人 SDK](https://github.com/WecomTeam/aibot-node-sdk)。[飞书 OpenAPI MCP](https://github.com/larksuite/lark-openapi-mcp)提供更广泛的工具和 OAuth 接入；官方[企微 OpenClaw 插件](https://github.com/WecomTeam/wecom-openclaw-plugin)提供面向该宿主的适配。[dsh-connect](https://github.com/IvanWu2015/dsh-connect)是支持飞书等平台的社区 DH 消息插件。这些项目可供后续扩展参考；增强版使用原生设置和会话生命周期配合官方传输实现。当前限制见[包参考](../../packages/interaction/enterprise-connectors/README.zh.md)。
