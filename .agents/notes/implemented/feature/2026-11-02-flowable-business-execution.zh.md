# Agent Note: DH 中的 Flowable 业务执行

Status: implemented

[English](2026-11-02-flowable-business-execution.md) | 中文

## 问题

业务编辑器需要独立于浏览器状态的持久执行。模型指令无法强制节点顺序、审核等待或允许的系统操作。原[工作台决策](2026-11-02-business-workflow-workbench.zh.md)继续负责模块位置与手动模拟。

## 决策

Host 适配器、受限 BPMN 编译器、worker、共享数据、浏览器控制器及测试集中在 `packages/business-workflow/workbench`。通过现有 API 组合暴露已认证的 Typert Remote 命名空间。Flowable 8.0.0 负责实例、用户任务、接收等待、历史及外部任务。本地 Compose 使用固定摘要的官方多架构镜像、本机端口、私有凭证与 H2 命名数据卷；每次请求重新解析凭证，不发送给浏览器。

只将数据编译为限定的 BPMN 子集。名称进行 XML 转义，活动编号由程序生成，条件路由使用 Host 生成的布尔变量，用户文字不转换为可执行 EL 或脚本。提交草稿固定保存在引擎变量中，并按确切定义编号启动。部署使用独立租户，外部任务主题包含租户标识。

串行外部 worker 支持数据传递、标量条件与 DH 分析。没有实现的业务连接器动作保持等待。分析使用当前默认模型执行一个私有 DH 回合，工具可见集合为空、采用 native 展示，并由检查器拒绝所有工具执行。通过实时 Session 事件归集结果；只有回合正常完成且答案非空才完成引擎任务。调用模型前先记录 Session 编号；失败或结果不确定的尝试使用零次重试，不在崩溃后自动重复工作。

审核和等待命令检查所属流程与当前引擎任务，不提供任意节点完成接口。人工任务使用 DH 已认证的本机操作人；草稿角色说明不提供企业授权。等待确认记录本机回执并继续传递输入。退回会取消流程；取消及卸载会等待当前分析停止。

固定企微待办动作在私有本地作用域中复用原有办公工具执行器，按保存的账号与分类权限只请求首 10 项未完成待办；执行检查仅允许这个工具及确切查询，不调用模型。包含分页标记的参考输出交给另一个不带工具的分析节点；访问连接器前先记录尝试编号。示例停在人工确认处，不修改办公资源。真实引擎浏览器场景通过已交付连接器及测试 CLI、模型响应验证这条数据通路和单次读取。

明确标记为模拟的待办动作通过必填的 risk/routine 场景提供固定演示样本，不依赖凭证、连接器或模型。固定基准日及资料标记计算复核布尔值，网关不从模型文字提取决定。本地化分析任务分别分类样本和生成简报；风险路线在简报之前人工复核，两条路线都需最终确认。模板、节点输出及要求模型生成的文字保留模拟标记。独立动作和模板编号将真实企微读取与生成样本区分。

通过 `storageDomain` 持久化可编辑草稿和不可变的发布快照。发布先部署引擎定义再提交指针；提交中断可能留下未使用的引擎定义，但不会暴露尚未提交的发布版本。串行目录操作检查乐观版本，并阻止启动接受期间发布版本发生变化。固定的发现、启动、查询、终止工具每次读取目录，不为每个流程重建工具参数结构，从而保留稳定的工具前缀，并由执行器检查当前版本及输入。投递与发起方编号来自可信工具调用元数据。在发现、启动、查询或终止前检查本地对话祖先，防止企业远程会话的分支借本地 worker 读取办公数据。查询及终止要求确切的发起 Session；审核和事件确认仍由本机操作人通过 Remote 办理。

输入框选择器将本地 Session 与确切的流程／版本绑定，保存在业务目录中。用户选择是持久配置，不是执行请求。Agent 空闲维护在持久写入前认领变更，后续唤醒输入必须等操作完成。已记录的提示词上下文传达所选编号；提示词组装仅开放工作流工具，单调的工具检查独立拒绝其他调用，启动接受时再检查所选版本。按照[手动选择规则](2026-11-03-manual-workflow-selection.zh.md)，返回普通聊天恢复无关工具并阻止新的会话启动，不取消已有实例。仅在提示词中声明偏好不能强制此规则。[n8n Chat Hub 的交互](https://docs.n8n.io/advanced-ai/chat-hub/)支持聊天前选择已发布工作流；这里将流程选择与现有权限预设分开。绑定要求可直接调用工作流工具，仅使用 PTC 的 Agent 会拒绝选择，不改写原有展示模式。

## 考虑过的替代方案

浏览器状态不能持久工作，也不能约束重启后的 DH。执行浏览器提供的任意 BPMN、EL 或脚本，会授予超出编辑器节点集合的能力。给分析 Agent 开放通用工具，会使其绕过引擎执行后续系统操作。自动重试结果不确定的动作可能产生重复副作用。Flowable 维护的[外部任务 API](https://www.flowable.com/open-source/docs/bpmn/ch07b-BPMN-Constructs#external-worker-task)提供适用于 Node Host 的 REST 协议，无需将 Java 引擎嵌入 DH。

## 影响

工具提供方在通过选定执行器描述能力前应用只允许拒绝的 `tools/model-denied` 事件。工作流拥有方同时提供展示策略与执行守卫，因此原生和 PTC 说明不能恢复被省略的能力。会话跟进通过 `agent/created` 恢复；每次分析或连接器尝试在自身 Agent 作用域中挂载原生执行器，并使用执行器拥有的批次接口。

外部源码改动用于配置、编译引用、Remote 组合和依赖分类。`credentialRef` 与 `createUserMessage` 保持共享 peer 依赖，重复安装安全导出的例外列表不变。通用 Web bundle 保持默认禁用，中天配置显式提供引擎参数。服务端草稿及发布指针持久化到经过结构检查的 DH 存储域，提交实例跨浏览器及 Host 重载保留。相同请求编号的处理是本机去重加历史查询，不是分布式严格一次执行；变更型 REST 请求不会自动重试。

真实引擎测试使用隔离租户，覆盖路由、审核与等待越步拒绝、缺少连接器、取消及 Host 重载。构建后的 Loader／浏览器场景回放录制的 DH 回合，验证分析工具为空、办理真实引擎任务并刷新持久历史。其他业务连接器、办公写入、企业身份、已签名上游回执、分布式去重及不确定模型尝试的恢复不属于本次集成。
