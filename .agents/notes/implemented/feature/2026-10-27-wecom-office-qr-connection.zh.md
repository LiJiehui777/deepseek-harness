# Agent Note: 企微办公扫码连接

Status: implemented

[English](2026-10-27-wecom-office-qr-connection.md) | 中文

## Problem

智能机器人传递消息及任务，但不能提供办公文档、日程或待办访问范围。独立 DH 需要明确的办公授权，并避免远程机器人对话继承该账号。

## Decision

企微卡片的办公账号仅保留扫码、取消或断开这一个操作。扫码选择加入页面列出的办公能力。固定版本的官方 CLI 1.3.4 负责创建、绑定机器人并保存加密凭据。宿主的 AES-GCM 适配器读取同一机器人供官方 WebSocket SDK 使用，不向设置、Remote 接口或工具传递密钥。授权提交自动替换消息连接，断开会停止它。远程任务仍要求明确允许发送者；原生页面展示任务权限，不要求填写机器人凭据。扫码机器人的会话查询和发送使用 CLI 固定接口，发送需校验近期会话并获得原生确认。手动机器人保留[企业连接器规则](2026-10-13-standalone-enterprise-connectors.zh.md)。[办公操作决策](2026-10-27-wecom-office-operations.zh.md)在固定读取基础上扩展基于参数定义的办公读取与经确认的修改。执行器检查已保存的能力开关及可信 Session 祖先，拒绝企业任务 ID、派生对话、循环祖先及无法解析的父对话。

每次授权尝试拥有独立的私有代次目录。CLI 在其中保存加密凭据，原生授权记录只存绑定主目录的路径引用。适配器移除继承的 CLI 覆盖项，抑制原始诊断并限制输出。读取针对已保存账号串行执行，使用独立输出目录并投影选定字段，文档文件必须位于本次调用目录内。取消、替换、断开及卸载会等待进程清理，迟到的授权确认不能写入已替换绑定。

方法发现仅标记接口可用，成功读取后才标记资源访问已验证。只有平台返回已识别字段时才显示授权人及企业名称。一个 DH 主目录共享此办公账号。官方 CLI 的扫码模型不是可与飞书用户身份互换的个人 OAuth 令牌。

## Alternatives considered

- 复用 Bot ID 和 Secret 会混淆消息传输与办公权限，也不能提供办公接口。
- 任意 CLI 命令会开放超出已批准读取范围的写操作。
- 将该授权提供给远程任务，会使获准派任务的机器人发送者继承本地办公账号，开放前需要独立的远程办公权限及确认规则。
- 把办公文档复制到 RAGFlow 会引入同步和保留职责。读取作为参考进入 DH 对话，RAGFlow 保持为独立连接器。

## Consequences

部署需要精确版本的 CLI 依赖，每个主目录限制一个账号。办公操作遵守明确的分类权限和平台资源授权；连接不授予不受限制的聊天存档。断开删除本地凭据，不撤销平台授权。不同企业的接口能力存在差异：模拟传输测试验证 DH 集成，真实扫码及有权文档读取验证账号访问。Loader 测试覆盖取消及读取隔离，原生页面测试覆盖暂存设置、二维码取消及本地 Agent 执行。
