# Agent Note: 独立业务工作流工作台

Status: implemented

[English](2026-11-02-business-workflow-workbench.md) | 中文

## 问题

业务流程需要在 DH 内配置，同时避免把 MES、SDCC、EIP 的逻辑分散到 Agent 循环和现有客户端包。第一步需要在接入生产引擎与连接器前，明确展示节点顺序与审核步骤。

## 决策

功能集中在 `packages/business-workflow/workbench`，通过现有 slots 注册主面板与侧栏入口。通用 Web bundle 包含但禁用本插件，中天 overlay 启用。注册持有的 store 保存当前页面的草稿及独立预览快照；JSON 导入导出用于刷新页面后继续编辑。

分组节点侧栏将基础信息、执行参数、输入引用、条件与后续路径分开。正文独立滚动，标题与删除操作位于该滚动区域外，避免长提示词或条件表单隐藏节点身份及删除入口。侧栏编辑现有草稿字段，并保留开始和结束节点保护；删除节点时保留下游悬空引用供检查，不自动改变数据含义。布局参考 [Dify If-Else 面板](https://docs.dify.ai/en/use-dify/nodes/ifelse)的变量与条件分组，使用 DH 的主题及表单组件。

预览仅通过显式模拟操作推进。人工与等待节点拒绝普通推进，终态预览不能恢复。预览不调用模型、连接器或流程引擎；模拟审批不授予业务权限，界面明确说明这些限制。真实执行由独立的 [Flowable 决策](2026-11-02-flowable-business-execution.zh.md)负责。

本决策不取代[动态工作流](../../../../packages/workflow/workflow/README.zh.md)：原功能负责模型驱动的工作流执行，本包负责业务流程编排与模拟。

## 考虑过的替代方案

将业务控件加入聊天或现有 workflow 服务，会把编排与模型执行耦合。独立托管原型无法验证 DH 面板注册。立即集成 Flowable 会将界面评审与引擎部署、连接器访问混在一起，超出第一步范围。

## 影响

业务界面及测试集中存放；外部改动仅用于编译器、bundle、overlay 与浏览器测试配置的注册。草稿检查覆盖支持的无环图及上游引用，不验证运行时业务条件。草稿跨面板切换保留，刷新前必须导出。预览记录最多二十条。

包内测试覆盖导入检查、图编辑、预览状态转换及注册释放。构建后的 Web 场景通过中天 overlay 验证实际 Loader 组合，复用现有模型录制回合，并拥有本地工作流界面预期。Flowable 集成验证引擎执行、持久化及分析工具限制；真实连接器和企业审批身份需单独接入。
