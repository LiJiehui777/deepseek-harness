# Agent Note：基于参数定义的企业微信办公操作

Status: implemented

[English](2026-10-27-wecom-office-operations.md) | 中文

## 问题

已连接的办公账号需要通讯录、会议和邮件操作，以及文档、表格、日程、待办和微盘修改。少量只读适配无法覆盖官方方法目录，同时避免重复维护参数定义或放开任意命令。

## 决策

[扫码账号决策](2026-10-27-wecom-office-qr-connection.zh.md)继续管理凭据归属、可信本地 Session 祖先检查和机器人成员权限。固定且经审查的方法清单为每项操作指定分类与读写模式。能力发现、参数发现、读取和写入使用不同的原生工具。官方新增方法需要修改代码才能接入。Host 获取所选官方参数定义，不做类型转换地验证参数，并仅投影声明的响应字段，移除凭据及身份上下文。参数说明和资源内容始终作为参考数据。

修改执行器在验证参数和复制待上传文件后，自行请求原生单次确认，其他调用方不能绕过。拒绝、缺少或取消确认时不会提交修改。在提交和发布结果前再次检查账号与分类权限。结果不确定的写入绝不自动重试。消息目标必须出现在已绑定机器人的最近会话列表中。

新增的通讯录、会议、邮件和聊天权限默认关闭。已有账号明确启用办公扩展；新扫码连接选择加入页面列出的能力。上传仅复制可信本地工作区内的普通文件，排除 DH 私有目录、账号目录及凭据文件。下载来源必须位于本次调用的私有目录，文件保留到新的工作区目录。字节数、条目数、文件数和时间均受限制；失败时清理尚未发布的下载文件。后续本地表格分析与编辑由 DH 普通文件工具负责。

## 考虑过的替代方案

- 放开任意 CLI 命令会在未经审查时接入授权命令和新修改方法。
- 每个官方方法注册一个原生工具会重复维护发现逻辑，并增加模型的常驻参数成本。
- 将扫码成功视为所有业务权限验证，会掩盖资源和归属限制。

## 影响

方法发现只能证明参数兼容，不能证明具体资源可访问。确认后仍可能出现平台错误或单条操作失败。企微决定归属、聊天历史可用性和企业策略。本地文件传输需要本地工作区。[连接器包](../../../../packages/interaction/enterprise-connectors/README.zh.md)维护执行限制及尚不支持的行为。Loader 测试使用外部夹具验证官方参数适配；无需密钥的 Web Session 记录发现、读取和原生写入确认。
