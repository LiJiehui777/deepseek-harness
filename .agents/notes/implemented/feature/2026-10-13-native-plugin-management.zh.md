# Agent Note：原生插件管理迁移

Status: implemented

[English](2026-10-13-native-plugin-management.md) | 中文

## 问题

独立增强版需要接入最新原生插件管理入口，同时保留既有连接器、账号授权及对话数据。

## 决策

迁移固定到上游 `d743267388`（0.2.1-alpha.2）的官方 plugin-manager 及 ui-plugin-manager 源码。保留插件检查、取消、源选择、构建脚本显式批准、兼容性检查及管理依赖保护。将配置串行化、根 Include 重组、共享配置表单、本地化及基础组件适配到当前运行时。增强版配置组合新插件包及既有连接器。独立的中天品牌启动覆盖层使应用标识不依赖连接器组合。连接器拥有的图标通过键控 `plugins.item.icon` 插槽注册，供卡片和详情共用，插件管理器无需识别提供方专用 id。飞书凭据及 OAuth 保持既有归属。可选统计采用显式嵌入回调，普通网页启动不提供该回调。

## 考虑过的替代方案

完整合并上游会替换大量无关运行时及会话接口，仅改界面列表又不能控制 Loader。选择性迁移保留原生行为，同时保持独立架构。

## 影响

设置、凭据及对话保留在原 DH 主目录。增强版插件选择独立于旧 Web 配置。RAGFlow 仍是独立 API 服务。本迁移不增加 CLI 插件子命令，也不自动满足外部插件对新版运行时的要求。

## 验证

保留上游插件包、源选择、补丁、生命周期及浏览器控制器测试。构建后的网页验证三个表单、凭据引用保存、按名称选择知识库、设置刷新及 Loader 实际工具卸载重载。既有 RAGFlow 选择器和飞书 OAuth 测试继续作为回归验证。增强版组合验证中天品牌和浏览器图标，原生连接器卡片和详情验证各自的平台标识。
