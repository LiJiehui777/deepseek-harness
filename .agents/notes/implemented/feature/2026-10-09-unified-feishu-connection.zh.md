# Agent Note：统一飞书连接

状态：已实现

[English](2026-10-09-unified-feishu-connection.md) | 中文

## 问题

机器人渠道凭据不能表达文档、多维表格访问、用户授权或每个对话选择的能力。

## 决策

可选的[飞书连接插件包](../../../../packages/interaction/tool-feishu-connection/README.zh.md)通过私有对话预设，只添加选定的群聊、文档和多维表格读取工具。空的部署补丁不提供全局工具。RAGFlow 管理应用凭据、每个用户的加密 OAuth 授权和能力选择；每次读取解析当前保存的连接和授权。模型参数不能选择其他账号。用户身份失败不回退到应用身份。

原生设置的插件服务连接页将管理交给 RAGFlow。用户授权请求绑定用户与应用，只能使用一次，十分钟后过期。刷新租约和授权版本阻止并发轮换，并防止断开的授权被刷新覆盖。资源链接解析为标识符，只请求固定的官方 API 域名。飞书共享和成员规则继续生效。

## 考虑过的替代方案

把平台令牌复制到浏览器设置或模型参数会暴露权限。在进程中启用全部工具会扩大无关对话的访问范围。已冻结的会话读取插件包保持原样，因为已有运行目录固定构建摘要；新对话使用统一连接。

## 影响

对话内选定的能力 schema 保持固定，宿主当前的授权状态可以撤销执行权限。Docx/Wiki 和多维表格结果使用标准的持久化工具文字；不提供附件下载或写操作。需要在飞书后台开通并发布应用身份或用户身份权限。真实租户授权和资源访问需要使用获准账号手动验证。

## 验证

Loader 组合以完整源码覆盖率固定六个工具 schema、能力收敛、卸载和完整结果失败。无需模型密钥的[飞书连接会话](../../../../snapshots/session/feishu-connection/snapshot.yml)通过正式 headless 部署运行文档、数据表、字段和记录读取。构建后 Web 预期固定连接管理页和未发送草稿保留。Gateway 安装冒烟验证官方原生插件命令与私有预设选择。
