# Agent Note: 收起的会话搜索忽略自动填充

Status: implemented

[English](2026-10-29-collapsed-session-search-autofill.md) | 中文

## 问题

侧边栏在搜索收起后仍保留输入框。连接器显示凭证控件时，浏览器或密码管理器的自动填充可能修改这个不可见字段。非空查询会用搜索结果替换工作区分组，用户因此看到近似空白的侧边栏，却看不到筛选词。

## 决策

收起的输入框处于停用状态，并设置 `autocomplete="off"`。变化处理器只在搜索展开时接收输入值。打开搜索后可以正常编辑；清空后恢复浏览。侧边栏收起和展开时，已有查询与请求取消语义保持不变。

## 考虑过的替代方案

**只关闭自动补全**只是浏览器提示，不能拒绝输入事件。**卸载输入框**会改变现有焦点与过渡生命周期。**进入插件时清空搜索**会丢弃用户主动设置的搜索，也无法覆盖其他凭证表单。

## 结果与影响

连接器配置无法通过此字段激活不可见的会话筛选。在全局插件页面中，用户仍可主动搜索。修复只改变显示交互，不修改工作区成员或会话存储。组件回归用例通过模拟自动填充的变化复现空列表现象；构建后的 Web 测试打开连接器详情，检查既有工作区行与成员仍然可用。
